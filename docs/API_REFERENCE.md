# 📡 API Reference & OpenAPI Endpoint Catalog

This document specifies the RESTful API endpoints available in the **SNIST AI QR Attendance System** under the prefix `/api/v1`.

---

## 1. Authentication & Session Endpoints (`/api/v1/auth`)

### `POST /api/v1/auth/login`
Authenticates users with username/roll number and password/PIN, enforcing device binding rules.
- **Request (Form Encoded)**:
  - `username`: Institutional Roll Number or Staff Username (e.g. `23311A05Y6` or `sowjanya`)
  - `password`: Password or Student 4-6 digit numeric PIN
  - **Headers**:
    - `x-device-public-id`: Hardware UUID generated by client device
    - `x-device-secret`: Cryptographic device secret
- **Responses**:
  - `200 OK`: `{"access_token": "...", "token_type": "bearer", "role": "STUDENT"}`
  - `401 Unauthorized`: Invalid credentials
  - `403 Forbidden`: Account switching lockout (device bound to another account)
  - `429 Too Many Requests`: Too many failed login attempts

### `POST /api/v1/auth/refresh`
Refreshes an expired JWT session using valid device credentials.
- **Request Body**: `{"device_public_id": "...", "device_secret": "..."}`
- **Response**: `200 OK` with fresh `access_token`.

### `GET /api/v1/auth/me`
Retrieves authenticated user profile and academic metadata.
- **Headers**: `Authorization: Bearer <JWT>`
- **Response**: `200 OK` with user details, assigned sections, and role.

## 2. Classroom Attendance Endpoints (`/api/v1/attendance`)

### `POST /api/v1/attendance/scan-projector`
Invoked when a student scans the classroom projector rotating QR code.
- **Headers**: `Authorization: Bearer <STUDENT_JWT>`, `x-device-public-id: <UUID>`
- **Request Body**:
  ```json
  {
    "token": "signed_rotating_projector_token",
    "latitude": 17.3850,
    "longitude": 78.4867
  }
  ```
- **Responses**:
  - `200 OK`: `{"status": "SUCCESS", "message": "Attendance marked successfully!"}`
  - `400 Bad Request`: Expired QR code token (outside 20s server tolerance)
  - `409 Conflict`: Duplicate attendance already recorded for this session

### `POST /api/v1/attendance/scan`
Invoked by faculty scanner reading a student's dynamic QR code.
- **Headers**: `Authorization: Bearer <TEACHER_JWT>`
- **Request Body**: `{"qr_token": "student_dynamic_token", "session_id": 29}`
- **Response**: `200 OK` with student verification status.

## 3. Faculty Dashboard Endpoints (`/api/v1/teacher`)

### `POST /api/v1/teacher/sessions/start`
Starts a new live attendance session for a class.
- **Headers**: `Authorization: Bearer <TEACHER_JWT>`
- **Request Body**:
  ```json
  {
    "section_id": 1,
    "subject_id": 12,
    "period": "Period 1-4 (4 Periods Block)"
  }
  ```
- **Response**: `200 OK` with new `session_id`.

### `GET /api/v1/teacher/sessions/{id}/projector-token`
Generates the active 10-second rotating HMAC token for the classroom projector.
- **Response**:
  ```json
  {
    "token": "ey...",
    "expires_in_ms": 7850,
    "window_index": 178859918,
    "active_count": 42
  }
  ```

### `POST /api/v1/teacher/sessions/{id}/lock`
Locks the session, finalizes attendance, and queues background sync to Google Sheets and Master Excel.
- **Response**: `200 OK` with finalized attendance count and sync status.

## 4. Student Onboarding & Self-Service (`/api/v1/onboard`)

### `POST /api/v1/onboard/send-otp`
Dispatches a 6-digit verification code to the student's institutional email via Zoho OTP channel.
- **Request Body**: `{"token": "magic_token"}`
- **Response**: `200 OK` `{"status": "SENT", "channel": "OTP"}`

### `POST /api/v1/onboard/verify-otp-and-set-pin`
Verifies OTP code and sets the student's permanent login PIN.
- **Request Body**:
  ```json
  {
    "token": "magic_token",
    "otp": "491823",
    "pin": "1461",
    "device_public_id": "DEV-UUID-001",
    "device_name": "Samsung Galaxy S23"
  }
  ```
- **Response**: `200 OK` `{"status": "ONBOARDED", "message": "Account activated successfully!"}`

## 5. Super Admin Endpoints (`/api/v1/admin`)

### `POST /api/v1/admin/security-alerts/test-send`
Triggers an immediate synthetic test alert to `settings.SECURITY_ALERT_EMAIL`.
- **Headers**: `Authorization: Bearer <SUPER_ADMIN_JWT>`
- **Response**:
  ```json
  {
    "status": "SENT",
    "target_email": "23311a05y6@cse.sreenidhi.edu.in",
    "channel": "Default/Helpdesk",
    "latency_ms": 142.5,
    "server_time_ist": "05-Sep-2026 16:35:40"
  }
  ```

### `GET /api/v1/admin/audit-logs`
Queries system audit trail with keyset-cursor pagination.
- **Query Parameters**:
  - `last_id`: Keyset cursor ID (integer)
  - `limit`: Number of records (default: 20, max: 100)
  - `event_type`: Optional event filter (e.g. `ACCOUNT_SWITCH_ATTEMPT`)
